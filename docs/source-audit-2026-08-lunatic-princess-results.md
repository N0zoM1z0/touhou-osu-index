## Corrected osu! search

An early diagnostic report produced inconsistent candidate IDs and was discarded wholesale. No candidate number from that report was reused. A separate sanity run first proved that osu! API search-result `id`, artist, and title round-trip exactly through `/api/v2/beatmapsets/{id}`. The systematic search was then rerun from zero with a hard same-run identity assertion for every source-matched result.

Final corrected funnel:

- source-backed corpus: **191 tuples**;
- osu! search queries: **194** (the corpus plus controlled aliases such as `Taketori Hishou`, `Flight of the Bamboo Cutter`, `Help me, ERINNNNNN!!`, and artist-guarded `Tsurupettan`);
- unique osu! search hits examined: **5,070**;
- exact source-backed title/artist or controlled-family matches: **26**;
- already accepted in the catalog: **10**;
- individually reviewed: **16** = 9 absent + 7 existing candidates;
- accepted after direct refetch and composition review: **16**;
- direct-refetch errors or search-to-direct ID/artist/title mismatches among those 26: **0**.

The other **5,044** search hits were not promoted to review candidates. Search ranking is intentionally noisy: for example, `nmk sola` returned an unrelated `Ono Hideyuki - sola`, and a `GET IN THE RING Moonscraper` query returned unrelated token matches. Exact artist/title guards rejected these before catalog review.

All 16 reviewed entries receive `audit:lunatic-princess-2026-08` and structured provenance:

- `origin_games = ["東方永夜抄 ～ Imperishable Night."]`;

- beatmapset 2314117 is `touhou_kind: mixed`;
- the other fourteen are `touhou_kind: arrangement`.

Verification itself is deliberately split by evidence strength:

- **6** use the normal classifier because current osu! `source` is an exact Touhou/game source: 21098, 47754, 855735, 2205747, 2282709, 2561367;
- **1** uses existing audited official-pack evidence (`official_pack_item:A23`): 2626;

No `manual:verified` marker is added merely because a search query matched.

## Conservative scope note

This audit does **not** claim to have exhausted all 1,758 Arrangement Chronicle rows. The 191-tuple corpus is a deliberately high-value searchable subset, broadened beyond obvious title aliases. It is intended to increase recall while keeping every accepted osu! beatmapset individually defensible. Further waves can extend the corpus without weakening the acceptance threshold.
